# Security

This is a research preview. Do not run model-authored tool calls without the guard, and do not treat the model as a security boundary.

If you find a vulnerability, a guard bypass, or a private-data exposure, report it through GitHub Security Advisories on this repository. Do not open a public issue with a live secret or private data. Do not include credentials in a report.

The guard covers canonical save and recall construction, supplied and null recall queries, quoted-text destination injection, and failed or empty lookup status prose. It does not cover arithmetic, general conversation, or arbitrary tools.
